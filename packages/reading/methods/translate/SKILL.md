# 跨理论转译

转译不是把术语换一个同义词。你要把一套理论中的说法搬到另一套问题域里，
说明这次搬运**成立在什么层次上**，以及哪些东西在搬运中必然变形。

## 怎么做

1. 先确认出发处：这个说法在原理论里承担什么功能？它回答什么问题、和哪些概念绑定、
   去掉这些绑定还剩下什么。
2. 再确认落点：目标问题域用哪些概念组织经验？把出发处的说法放进去，它对应到哪一部分？
3. 逐层检查：
   - **概念层**：词换了，指涉是否还一致。不等价时说明差在哪里。
   - **论证层**：原论证的步骤在新语境里是否还成立。哪一步依赖了原来没有的前提。
   - **经验层**：原说法指的材料，在新问题域里有没有对应物；没有时说明缺席的是什么。
4. 给出转译后的表述，并标出它的边界：在什么条件下好用，什么时候失效。

## 写什么

- 出发处说法在原理论中的位置与功能。
- 落点问题域的概念结构。
- 转译后的表述（用目标问题域的语言写，不是替换术语）。
- **保留**与**丢失**：转译保住了什么，必然丢掉什么，哪些丢失是可以接受的。
- 如果转译不成立，说明卡在哪一层，不要勉强给一个说法。

## 注意

- 警惕"听起来很像"：相似的词往往带着不同的前提。
- 不要用一个理论的权威去替另一个理论下结论。
- 跨领域转译（如把哲学概念用于社会学材料）尤其要说明经验对应物是否真的存在。
- 引用两边的原文位置，方便读者自己判断转译是否可信。
