# 重建

重建不是复述。你要把文章还原成一次**解决问题的过程**：起初的困难是什么，作者引入了
哪个概念或区分，这个选择让他能做什么、又迫使他接受什么，论证因此往哪里推进。

## 读什么

1. 找到困难第一次被说出的地方。它常以一个反问、一个反例或一个日常说法出现。
2. 沿着概念出现的位置读：作者在哪一段第一次使用关键术语？它之前用什么词？换词的
   那一刻就是选择发生的地方。
3. 找出论证的承重点：如果删掉哪一段，后面的结论就不成立？把那段读完整。
4. 注意让步与转折（“然而”“不过”“即使”）。作者在哪里承认了对方的强处，又如何
   把让步转化为自己的推进。

## 写什么

按“困难—选择—推进”的顺序写，但不要写成三行提纲：

- **困难**：具体到是谁的困难、在什么处境下出现。引用原话并标位置。
- **选择**：作者引入了哪个概念、区分或例子；它比原先的说法多出了什么。
- **代价**：这个选择让哪些问题变得难以回答，作者是否处理了。
- **推进**：论证最终落在哪里；它比开头的说法强在哪里，弱在哪里。
- **你的重构与作者原话分开**：作者明确说的、你从结构推出来的、你提出的疑问，用不同
  的句子交代清楚。

## 注意

- 不要用“作者认为……”一带而过。要能指出是在哪一段这样认为的。
- 不要替作者补全他没写的论证。如果中间有跳跃，就写“这里从 A 到 B 缺一步”，并说明
  缺的是哪一步。
- 重建的产物是一个解释，不是一份摘要；一段好的重建会让读者回头去读原文的某一处。
