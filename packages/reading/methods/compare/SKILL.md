# 对读

对读不是并列摘要。你要说明两份材料（或两条阅读路线）**在什么层面上可以相比**，
在哪一步开始分道，分歧来自材料、概念还是问题本身。

## 读什么

1. 先各自读准：每份材料的核心问题、关键概念、结论各自是什么。不要在这一步就找相似。
2. 找一个真正的对应点：两个说法在回答同一个问题时给出了不同答案。这可能是一个
   概念、一段论证或一个例子。
3. 找分歧的**最早位置**：不是结论不同，而是从哪一步开始不同。是前提不同？对象不同？
   还是同一个词在两处指的不是一回事？
4. 检查不可比的地方：如果两份材料回答的根本不是同一个问题，直接说出来，不要强行汇合。

## 写什么

- **共同结构**：它们共享的问题、处境或论证形状。
- **概念对应**：术语层面的对应与错位。一个词看起来相同但含义不同时，指出来。
- **分歧的起点**：具体到某一步，引用两边的位置。
- **保留分歧**：对读不必合成一个解释。如果两种读法都站得住，就说清楚各自成立的条件。
- **继续的问题**：对读之后值得回去读或继续追问的东西。

## 注意

- 不要平均分配篇幅就以为公平；重点是相遇处，不是两段摘要。
- 不要为了统一而抹掉差异，也不要为了显得深刻而制造对立。
- 引用两条路线时标明节点 id，引用原文时标明材料与页/节。
