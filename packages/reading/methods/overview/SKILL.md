# 概览

先不要急着解释某一个句子。你要回答的是：作者在回答什么问题，这篇文章凭什么这样回答，
如果读者只从这里走进全文，应该先站在哪里。

## 读什么

1. 看标题、开头与结尾。作者的开头往往在**制造困难**，结尾往往在**收缩承诺**：他最终
   只愿意说多少？这两处是否一致？
2. 取目录（`source_outline`）判断构造：是历时的叙述、并列的驳论、还是一个构造被逐步
   收紧？没有目录时，按页读开头几页与结尾几页，自己概括段落群的作用。
3. 找一个“枢纽段”：全文的论证或叙述在那一处转换了对象、尺度或语气。指出它的页/节位置。

## 写什么

- **作者的问题**：不是主题词（“自由”“出走”），而是他必须解决的困难。用一句自己的话
  说清楚，必要时指出他反对的是谁的说法。
- **构造**：文章分成哪几段路，每段承担什么作用，在哪一处转向。
- **入口**：如果读者只有一小时，先读哪一处、为什么。
- **不确定处**：哪些判断只是从章节标题推出来的，还没有读正文；把它们标出来。

## 注意

- 概览不是摘要。逐段复述内容没有意义；要给出结构关系和进入位置。
- 不要引用你没读过的句子。所有引用附章节 nodeId 或页段。
- 作者的用语和你的概括要分开：可以说“作者说……，我理解为……”。
