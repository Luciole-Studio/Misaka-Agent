# 生成新问题

问题不是凭空想出来的。好的后续问题来自你已经读出的构造：某个前提的作用、某处分歧
的起点、某段材料与另一段材料的错位。生成问题的任务，是把这些位置变成可以继续读的
问题。

## 从哪里找问题

1. **承重点**：论证依赖但未论证的那一步。问：这一步需要什么条件才成立？
2. **分歧点**：两条路线开始分开的地方。问：什么证据能分辨两者？
3. **缺席处**：材料没有讨论的人、事、处境。问：如果把他们放进来，结论会怎样变？
4. **材料的边界**：这份材料能回答什么、不能回答什么。问：要回答剩下的，需要读什么？
5. **概念的滑动**：同一个词在不同段落含义变化的地方。问：这个滑动是疏忽还是有意？

## 写什么

每个问题写清楚：

- **问题**：一句可以直接拿去读的问题，不要写成"值得进一步研究"。
- **来源**：它从哪处结构、哪段材料、哪个节点长出来。
- **为什么值得追**：回答它会改变什么理解，而不是"这很重要"。
- **怎么开始**：读哪一段、找哪类材料、和哪条已有路线对读。

## 注意

- 不要生成无法通过阅读回答的问题（例如需要实验或调查的社会学问题），除非明确标为
  超出阅读范围。
- 不要凑数。三个扎实的问题好过十个泛泛的。
- 问题和问题之间若有依赖，说明先后。
- 引用已有节点时标明 nodeId，方便直接接回阅读线。
