新建研究

计划审批、压缩阈值与输出上限沿用现有研究设置。启动后在研究记录中查看进度，进入研究对话确认计划或提出修改。第一次建议深度 1、节点上限 3。

一次研究的路径

  1. 共同制定计划明确问题、证据与成员分工
  2. 并行调查与写作阅读材料，形成可追溯的结论
  3. 审查与答辩核查论证，回应反证与缺口
  4. 分叉与汇合探索替代可能，汇总研究报告
